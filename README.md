## Descripción

Sistema web que permite a microempresas de servicios personales gestionar el agendamiento de citas, el seguimiento de los servicios prestados y el control de pagos. El cliente puede consultar disponibilidad, reservar y gestionar su cita de forma autónoma.

## Tecnologías

- **Backend:** Node.js (LTS) con Express
- **Base de datos:** MySQL 8
- **Frontend:** HTML, CSS y JavaScript
- **Seguridad:** JWT con expiración y bcrypt para el hash de contraseñas
- **Control de versiones:** Git y GitHub

## Módulos

1. Autenticación y perfiles
2. Agenda interna del negocio
3. Agendamiento en línea para el cliente
4. Historial de atención
5. Control de pagos

## Metodología

Desarrollo iterativo e incremental bajo el marco Scrum, organizado en sprints con entregables verificables.
